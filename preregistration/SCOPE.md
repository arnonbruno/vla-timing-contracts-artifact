# Study C scope notes

Primary Study C uses fixed Exit-3.

A learned progressive controller met a preregistered relative competence
criterion (mean J ratio 1.211 <= 1.25) but produced 0/600 shallower
deadline-conditioned admissions. The reported deadline envelope is therefore
not claimed to generalize to adaptive exit selection.

Deadlines D_L=71 ms, D_B=61 ms, D_T=51 ms were frozen from an independent
latency-only calibration before any tracking outcomes were examined.
